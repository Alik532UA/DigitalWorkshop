# Документація проєкту DigitalWorkshop

## Призначення
Інженерна документація, стандарти та архітектурні рішення інтерактивної студії `DigitalWorkshop`.

## Структура
- `adr/` — Архітектурні рішення.
- `specs/` — Специфікації аудіо-модулів та інструментів.
- `analysis/` — Звіти з оптимізації рендерингу та Canvas.
