# docs/

Звіти й аналізи проєкту, які варто тримати в репозиторії.

Правила для цієї папки (DOCUMENTATION-v8 § 3):

- **Дата в назві файлу** — `<тема>-YYYY-MM-DD.md`. Звіт без дати через півроку
  не відрізнити від актуального стану, і саме так з'являються два документи, що
  суперечать один одному.
- **Назви — ASCII, kebab-case.** Ніякої кирилиці в іменах файлів.
- **Frontmatter із полем `Статус`** — щоб було видно, це пропозиції чи вже
  впроваджене рішення.

Робочі нотатки, чернетки й усе, що не має жити в репозиторії, — у `.private/`
(вона в `.gitignore`).
